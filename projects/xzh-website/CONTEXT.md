# Personal Website (Agent Development Portfolio)

A focused, high-performance personal portfolio website presenting technical competency and learning progression in software engineering and AI agent development.

## Core Structure

1. **Hero**: Professional introduction, tagline, and direct contact channels (GitHub, Email, Twitter/X, Resume).
2. **About / Philosophy**: Engineering mindset, Zero-to-Senior learning path, and problem-solving approach.
3. **Projects / Case Studies**: Structured evidence area with modular slots for incoming project case studies.
4. **Skills & Tools**: Core web fundamentals, programming languages, and agentic toolchains.
5. **Contact**: Quick-reach communication channels and links.

## Language

**Flagship Case Study**:
A structured, evidence-backed breakdown of an end-to-end project (Problem, Architecture/Approach, Failure Modes Handled, and Verifiable Outcomes).
_Avoid_: Project showcase, portfolio gallery

**Agent Stack**:
The technical layers supporting software and agent operations: Core Foundations, Tool Harnesses, Context Management, and Telemetry.
_Avoid_: Tech stack, skill list

**Contact Channel**:
A direct communication endpoint (GitHub, Email, Twitter/X, or Resume download).
_Avoid_: Contact form, social widget
